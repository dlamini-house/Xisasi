# Xisasi Cancer Foundation Static Website

A vanilla HTML, CSS and JavaScript website based on the redesigned cancer foundation mockups.

## Included pages
- `index.html` — Homepage
- `campaigns.html` — Campaign listing with category/search filtering
- `campaign-detail.html` — Donation/campaign detail page
- `events.html` — Events listing page
- `stories.html` — Stories/resources page
- `start-fundraiser.html` — Static fundraiser form

## File structure
```text
xisasi-foundation-website/
├── index.html
├── campaigns.html
├── campaign-detail.html
├── events.html
├── stories.html
├── start-fundraiser.html
├── css/styles.css
├── js/main.js
└── assets/
    ├── logo.svg
    ├── favicon.svg
    └── images/
```

## How to run
Open `index.html` in your browser, or upload the folder to any static hosting platform.

## Notes
- This is a front-end demo only. Donations, user accounts, payment processing, fundraiser submissions and email subscriptions will need backend integration.
- All images used in the demo are included in `assets/images/`.
